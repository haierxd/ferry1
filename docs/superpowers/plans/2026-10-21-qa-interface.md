# 知序 AI Implementation Plan

**Goal:** 交付企业问答网页和 Figma 设计稿。

**Architecture:** 无构建依赖的静态前端，数据与行为由 app.js 管理，视觉规则由 styles.css 管理。Figma 用相同的颜色、字体、版面和内容创建原生图层。

**Tech Stack:** HTML / CSS / JavaScript / Figma Plugin API

**Spec:** ../specs/2026-10-21-qa-design.md

## Global Constraints

- 浅灰色为主体，包含机器人元素。
- 同时交付客户问答和智能体对话。
- 演示回复必须标注；不接真实 AI，不引入外部依赖。

## Tasks

- [x] 创建 index.html、styles.css、app.js；实现搜索、分类、问答、智能体选择、历史保存/恢复、新建会话和导出。
- [x] 浏览器验证桌面、移动端和主要交互，运行 JS 语法检查。
- [x] 创建 Figma 原生图层和复用组件；检查字体、图层类型与截图。
- [x] 更新使用说明并交付两个入口。

## Verification record

1440px 浏览器验证：售后搜索得到两个结果；无匹配输入显示空状态；项目交付分类得到两条问题；提问产生明确标记的示例回复；新会话为空且旧回复未串入；历史恢复正常；刷新后最近对话存在；输入 HTML 作为文字显示；智能体可切换。

375px 手机验证：文档宽度未超过视口；发现并修复机器人与标题拥挤，复查两者无重叠。Figma 图层检查两页共包含 136 个文本图层、25 个组件实例、90 个矢量节点；无 IMAGE 图层；字体均为 Noto Sans SC。截图修正卡片和页脚留白后通过视觉检查。

## Review Focus

- 无匹配问题显示清晰空状态。
- 输入中的 HTML 作为文字呈现。
- 本地存储禁用或损坏时不影响使用。
- 输入法确认不触发发送。
- 连续切换/新建会话不把异步回复插入错误会话。
