# 知序 AI 企业问答界面

用户选择同时交付原生 HTML/CSS/JavaScript 网页和可编辑 Figma 设计稿。

采用浅灰底色、白色卡片、青绿色强调色，中文字体 Noto Sans SC / Microsoft YaHei。桌面端以 1440px 为设计基准，左侧固定导航、顶部标题栏、主工作区。手机端折叠导航和右侧辅助栏。

客户问答页包含机器人欢迎区、搜索框、话题快捷入口、常见问题分类及折叠答案、知识专题、智能体入口。智能体对话页包含智能体切换、消息列表、推荐提问、输入框、参考资料、会话历史。交互为本地演示，不使用任何真实业务数据或虚构实时指标；实际 AI / 检索接口留待接入。

验证：页面正常渲染；搜索/无结果/分类有效；提问与演示回答有效；会话可保存和恢复；新会话与导出有效；小屏无横向溢出；Figma 有两个完整页面且以文本、矢量、组件实例构成。
